# Domain language

- Run: immutable evidence from one source checksum, month and rule version.
- Publication: pointer to the most recent run for a month that passed critical controls; it is not approval to pay salaries.
- Finding: a failed quality or reconciliation rule with severity, owner and remedy.
- Critical: a defect that blocks publication.
- Warning: evidence that needs review but does not itself block publication.
- Quarantine: invalid input excluded from reconciled records but represented in findings.
- Reconciliation: comparison of reported gross pay and a simplified expected gross amount.
